Dưới đây là thông tin chi tiết về khóa HTML/CSS của F8 Fullstack — đây là khóa nền tảng quan trọng nếu bạn muốn theo hướng Frontend hoặc Full-stack.

HTML CSS từ Zero đến Hero. Đây là khóa học nhập môn, dành cho: Người chưa biết gì về lập trình web. Người muốn xây nền Frontend vững chắc. Người chuẩn bị học JavaScript hoặc React.

Học miễn phí. Bạn có thể học toàn bộ khóa trên website F8 mà không cần trả tiền.
